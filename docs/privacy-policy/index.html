Privacy Policy — FileFlattener

Last updated: August 2026

FileFlattener is a Windows desktop application developed by Dvvyom Labs (Om Shivade). This policy explains what data the application does and does not collect.

Data Collection

FileFlattener does not collect, transmit, or store any personal data, usage analytics, telemetry, or diagnostic information. The application does not connect to the internet or any remote server during operation.

Local Data

FileFlattener reads and writes files only within folders explicitly selected by the user (for scanning, deduplication, and ZIP export). It stores a small local settings file (via Windows QSettings, under the registry key HKEY_CURRENT_USER\Software\FileFlattener) containing:

  • The list of the user's 5 most recently opened project folder paths
  • User interface preferences

This data never leaves the user's device and is not accessible to Dvvyom Labs or any third party.

Third-Party Services

FileFlattener does not integrate with any third-party analytics, advertising, or cloud services.

Children's Privacy

FileFlattener does not knowingly collect data from anyone, including children, because it collects no data at all.

Changes to This Policy

If this policy changes, the updated version will be published at this same URL with a revised "Last updated" date.
